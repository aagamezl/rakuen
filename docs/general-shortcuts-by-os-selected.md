## macOS deviations from the Selected column

A few actions intentionally diverge from the literal `Selected` binding because the literal choice would clobber a core native macOS shortcut. These are implemented in `hammerspoon/keybindings/general-system.lua`:

* **Show Desktop (#5):** trigger is `Ctrl+Cmd+D`, not `Win+D` -> `Cmd+D`. `Cmd+D` is natively Bookmark/Duplicate, so remapping it globally would be destructive. The action is sent as `Cmd+F3` (Mission Control), which is more reliable than the legacy `Fn+F11` on current macOS.
* **Minimize All (#11):** trigger is `Ctrl+Cmd+M`, not `Win+M` -> `Cmd+M`. `Cmd+M` natively minimizes the single focused window; it is preserved. The action is sent as `Cmd+Opt+M` (minimize all).
* **Show Hidden Files (#9):** trigger is `Cmd+H` -> `Cmd+Shift+.`, not the spec's `Ctrl+H`. `Ctrl+H` is already assigned to Find & Replace (#28), so the two cannot coexist. Note this overrides the native `Cmd+H` (Hide App).

## macOS caveats affecting implementation

* **Home / End (#34, #35, #42):** rules use the plain key (no `Fn`). Apple internal keyboards have no physical Home/End (`Fn+Left` = Home); external PC keyboards send them without `Fn`. The plain-key rules cover both, but should be confirmed on the target keyboard.
* **Screenshots (#49, #50):** there is no Mac PrintScreen. On external PC keyboards PrintScreen usually arrives as `F13`, so the rules trigger on `F13` / `Shift+F13`. Verify the emitted keycode on-device; if it differs, adjust the `from.key`.
* **Terminals:** all generic `Ctrl`->`Cmd` editing remaps carry an `except` for the terminal bundle IDs (see `hammerspoon/utils/app-groups.lua`) so shell/readline keys (`Ctrl+A/E/F/U/P/N/K/W`, etc.) remain native.
