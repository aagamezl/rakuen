# Docs

Here's a comprehensive table of cursor movement shortcuts for text editing on macOS and Linux:

## Basic Cursor Movement

| Action                   | macOS           | Linux (GTK)     | Linux (Qt/KDE)  |
|--------------------------|-----------------|-----------------|-----------------|
| Move left one character  | `←` or `Ctrl+B` | `←` or `Ctrl+B` | `←` or `Ctrl+B` |
| Move right one character | `→` or `Ctrl+F` | `→` or `Ctrl+F` | `→` or `Ctrl+F` |
| Move up one line         | `↑` or `Ctrl+P` | `↑` or `Ctrl+P` | `↑` or `Ctrl+P` |
| Move down one line       | `↓` or `Ctrl+N` | `↓` or `Ctrl+N` | `↓` or `Ctrl+N` |

## Word Navigation

| Action                      | macOS              | Linux (GTK) | Linux (Qt/KDE) |
|-----------------------------|--------------------|-------------|----------------|
| Move to beginning of word   | `Alt+←` or `Alt+B` | `Ctrl+←`    | `Ctrl+←`       |
| Move to end of word         | `Alt+→` or `Alt+F` | `Ctrl+→`    | `Ctrl+→`       |
| Move to previous word start | `Alt+←` or `Alt+B` | `Ctrl+←`    | `Ctrl+←`       |
| Move to next word start     | `Alt+→` or `Alt+F` | `Ctrl+→`    | `Ctrl+→`       |

## Line Navigation

| Action              | macOS               | Linux (GTK)        | Linux (Qt/KDE)     |
|---------------------|---------------------|--------------------|--------------------|
| Go to start of line | `Cmd+←` or `Ctrl+A` | `Home` or `Ctrl+A` | `Home` or `Ctrl+A` |
| Go to end of line   | `Cmd+→` or `Ctrl+E` | `End` or `Ctrl+E`  | `End` or `Ctrl+E`  |

## Document Navigation

| Action | macOS | Linux (GTK) | Linux (Qt/KDE) |
|--------|-------|-------------|----------------|
| Go to top of document | `Cmd+↑` or `Ctrl+Home` | `Ctrl+Home` | `Ctrl+Home` |
| Go to bottom of document | `Cmd+↓` or `Ctrl+End` | `Ctrl+End` | `Ctrl+End` |
| Page up | `Page Up` or `Ctrl+↑` | `Page Up` | `Page Up` |
| Page down | `Page Down` or `Ctrl+↓` | `Page Down` | `Page Down` |

## Text Selection (add Shift to movement shortcuts)

| Action | macOS | Linux (GTK) | Linux (Qt/KDE) |
|--------|-------|-------------|----------------|
| Select left by character | `Shift+←` | `Shift+←` | `Shift+←` |
| Select right by character | `Shift+→` | `Shift+→` | `Shift+→` |
| Select up by line | `Shift+↑` | `Shift+↑` | `Shift+↑` |
| Select down by line | `Shift+↓` | `Shift+↓` | `Shift+↓` |
| Select previous word | `Shift+Alt+←` | `Shift+Ctrl+←` | `Shift+Ctrl+←` |
| Select next word `(NOT WORKING AS INTENDED)` | `Shift+Alt+→` | `Shift+Ctrl+→` | `Shift+Ctrl+→` |
| Select to start of line | `Shift+Cmd+←` or `Shift+Ctrl+A` | `Shift+Home` | `Shift+Home` |
| Select to end of line | `Shift+Cmd+→` or `Shift+Ctrl+E` | `Shift+End` | `Shift+End` |
| Select to top of document | `Shift+Cmd+↑` or `Shift+Ctrl+Home` | `Shift+Ctrl+Home` | `Shift+Ctrl+Home` |
| Select to bottom of document | `Shift+Cmd+↓` or `Shift+Ctrl+End` | `Shift+Ctrl+End` | `Shift+Ctrl+End` |

## Notes

- **macOS**: In Terminal/iTerm2, you might need to adjust settings or use different shortcuts
- **Linux GTK**: Used by GNOME, Chrome/Chromium, Firefox, and many GTK-based apps
- **Linux Qt/KDE**: Used by KDE applications, Qt-based apps
- **Ctrl+B/F/N/P** work in many terminal applications and follow Emacs-style navigation
- Some applications may override these shortcuts with their own bindings
